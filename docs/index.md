# Introducción

En esta tarea se estudia la aplicación de la **cuadratura Gaussiana** 
para calcular la integral:

\[
I = \int_1^3 \big( x^6 - x^2 \sin(2x) \big)\, dx
\]

El objetivo es implementar el método de **Gauss-Legendre** en Python,
probar distintos valores de \(N\) y determinar a partir de qué orden 
se alcanza el resultado correcto (dentro de la tolerancia numérica).
